# FurnitureStore
 FurnitureStoreExample

Hello, this is my repository, here I will show you, what I've learned through the years of my programming experience!

To start the project, you need to navigate to furnitureProject and start it with the command 'ng serve' in the terminal.

For the Back-End side, navigate to restApi and start it with the command 'npm start' in the terminal.

Then you can open the site in your browser with this URL: 'http://localhost:4200/'

Enjoy my furniture site!
